# 详细交接手册

## 1. 目标与边界

本流程把一个已获授权的京东商品链接转换为当前商家自己的 POP 商品。自动化责任覆盖：采集、素材落盘、逐 SKU 定价、生成审核件、图片上传、合规校验、正式发布、发布后审计和主图视频全 SKU 绑定。

不覆盖：版权判断、选品决策、营销活动报名、价格长期跟价、订单履约和售后处理。

## 2. 当前成熟度

已在现代装饰画 `35381` 完成生产链路验证，包括：

- 多款式多尺寸商品；
- 源商品只有一个销售维度但规格文字含尺寸的商品；
- 多套主图；
- 全部详情图；
- 无品牌、印刷、七天无理由；
- 逐 SKU 反推京东价；
- 主图视频上传、转码、逐 SKU 绑定和审核；
- 重复运行的幂等恢复。

其他类目尚未验证，必须按新类目 MVP 流程适配。

## 3. 商家需要准备什么

每个链接最少需要：

- 已获授权的京东商品链接；
- 目标店铺已登录的 `jdo-cli`；
- 店铺 `venderId` 与准确店铺名称；
- 目标运费模板 ID 与名称；
- 目标类目的实时 Schema；
- 对默认规则有异议时，提供品牌、工艺、售后、库存、活动折扣、国补和优惠券参数。

无需人工准备：主图、SKU 图、详情图、源视频、逐 SKU 源价和审核 Excel；脚本从链接采集并落盘。采集不完整时会停止并要求补充。

## 4. 输入与输出

### 输入

- 单个 URL，或每行一个 URL 的 `links.txt`。
- `config/store.local.json` 店铺白名单和运费模板。
- 类目规则 JSON。
- 当前店铺、当前类目的实时 reference JSON。

### 每个商品输出

- `manifest.json`：源商品事实快照。
- `listing.json`：标准发品输入。
- `<商品目录名>.xlsx`：人工审核表。
- `主图/`、`SKU图/`、`详情图/`、`视频/`：本地素材。
- `.pipeline/`：上传、校验、发布和审计请求/响应证据。
- `outputs/migrations/state/<sourceSku>.json`：状态机、关键 ID、错误和恢复依据。

## 5. 端到端步骤

1. 从链接解析源 SKU。
2. 请求移动商品页，解析 SPU、标题、品牌、销售属性和 `newColorSize`。
3. 对每个真实 SKU 单独请求移动页，读取 `priceFloor.ext.jdPrice`。
4. 下载主图、SKU 首图、全部详情图；有视频则下载 MP4 和封面。
5. 根据源销售属性维度构造标准 listing，生成商家编码和价格。
6. 写出 JSON 与 Excel，执行本地预检。
7. 核对当前登录店铺与 `store.local.json`。
8. 查询店铺现有商品，按源 SPU 货号查重，并扫描编码前缀的最大款式号。
9. 上传图片并把图片 ID/URL 写回上传版 listing。
10. 生成发布 Schema，请求京东合规校验。
11. 用户显式确认后创建商品，并立即保存 `productId`。
12. 轮询商品详情，审计 SKU、价格、编码、属性、图片、详情和库存。
13. 若有视频，上传一次、保存视频、等待可用、逐 SKU 绑定并审计全部关系。
14. 所有检查通过后写 `VERIFIED`。

## 6. 价格策略

源价 F 必须逐 SKU 获取。默认：低同行 `0.10` 元，国补 `15%`，活动直降 `15%`，优惠券 `0`。

```text
K = ROUND((F - 0.10 + 0) / ((1 - 0.15) × (1 - 0.15)), 2)
L = ROUND(K × (1 - 0.15) × (1 - 0.15) - 0, 2)
```

京麦提交 K，不提交 F 或 L。L 是预计到手价，不是刚上架即生效的真实成交价。用户发布后自行批量报名活动。

任一 SKU 缺价、K/L 复算不一致或 `L != F-0.10` 时停止。

## 7. 图片规则

- 现代装饰画固定多套主图。
- 每款式第 1 张为专属图，第 2–10 张为公共图。
- 公共图即使 URL 相同也按每个款式完整提交。
- 详情图全部保留、保持顺序，不做主观筛选。
- 发布后按线上颜色 ID 审计图片组，不能只看 SPU 通用图。

## 8. 视频规则

- 页面称 SPU 主图视频，接口按 SKU 建关系。
- 一个视频上传一次，同一视频 ID 绑定所有 SKU。
- 首次取上传地址时省略 `breakPointFlag`。
- 绑定体为对象根节点，每次只放一个 SKU。
- 素材状态 `2` 或 `4` 都可复用；关系状态 `4` 才算审核通过。
- 已有其他视频、审核驳回或关系不完整时停止。

## 9. 商家编码

- 挂轴/卷轴：`GZH`。
- 粘贴/自粘：`ZTH`。
- 五位款式号从线上同前缀最大值加一。
- 尺寸后缀按实际尺寸从小到大使用 `A、B、C……`。
- 单维度规格也按规格文本解析尺寸，不新增前台尺寸属性。

## 10. 幂等和故障恢复

- 源 SPU 是商品查重键。
- `productId` 一旦返回即持久化。
- 视频 ID 一旦保存即持久化。
- 复跑先查已存在商品、视频和关系，正确项跳过。
- 新品详情传播延迟只轮询，不重发。
- 视频审核等待只轮询，不重复绑定。
- 每个源 SKU 有锁文件，避免并发重复处理。

## 11. 批量运行

先用一条链接确认配置与类目适配，再创建 `links.txt`。批量命令按顺序执行，任何商品失败立即停止；修复后再次运行，已完成阶段会复用。

不要同时从多个终端处理同一个源 SKU。不要在批量中混入尚未适配的类目。

## 12. 验收清单

- 登录店铺匹配白名单。
- 商品 ID 唯一且货号等于源 SPU。
- SKU 数量和组合一致，无灰色无效组合。
- 每个 SKU 京东价符合公式。
- 每个商家编码唯一且符合前缀、款式号和尺寸序。
- 库存专用接口显示目标绝对库存。
- 每个款式图片组完整，首图与公共图顺序正确。
- 详情图数量与源素材一致。
- 有视频时，全部 SKU 关系审核通过。
- 状态文件最终为 `VERIFIED`。

## 13. 已知限制

- 当前只有现代装饰画完成生产验证。
- 公开仓库不包含任何店铺实时 Schema、素材空间 ID、运费模板 ID 或登录凭据。
- 源价格可能受地区、会员、时段和风控影响；无法取得稳定逐 SKU 价格时停止。
- 营销活动由用户发布后处理，不验证前台实际活动价。
- 平台接口状态枚举和 Schema 可能变化，需要通过小样本回归后更新适配器。
