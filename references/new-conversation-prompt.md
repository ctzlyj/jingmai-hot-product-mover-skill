# 新对话提示词

请先加载并严格使用 `$jd-jingmai-hot-product-mover` Skill，继续优化“站内爆品自动搬运上架京麦”流程。

当前目标：输入一个或多条已获授权的京东商品链接，自动采集真实 SKU、逐 SKU 源价、主图、SKU 图、全部详情图和主图视频，生成标准 JSON/Excel，经审核后通过京麦 `jdo-cli` 安全发布，并完成商品与视频审计。

开始前请：

1. 阅读 Skill 的 `SKILL.md`、`references/handoff-manual.md`、`references/troubleshooting-and-stop-conditions.md`。
2. 先核验当前 `jdo-cli` 登录店铺与 `config/store.local.json` 白名单完全一致；不一致立即停止。
3. 检查当前类目的实时 reference 文件是否存在并适用于当前店铺；不要使用公开仓库中的示例值发布。
4. 先读取已有状态文件，禁止重复创建商品、重复上传视频或重复绑定审核中的关系。

现有已验证规则：

- 现代装饰画类目 ID 为 `35381`，固定多套主图。
- 无品牌、工艺印刷、支持 7 天无理由；运费模板来自店铺本地配置。
- 详情图默认全部保留并保持顺序，只告警，不主观删除。
- 保持源商品销售属性维度；源商品只有一个维度时不能擅自新增尺寸。
- 挂轴/卷轴编码前缀 `GZH`，粘贴/自粘前缀 `ZTH`；五位款式号加尺寸字母。
- 每个源 SKU 单独读取 `priceFloor.ext.jdPrice`。
- 默认 `G=0.10`、国补 `H=15%`、直降 `I=15%`、券 `J=0`。
- 京东价 `K=ROUND((F-G+J)/((1-H)*(1-I)),2)`；预计到手价 `L=ROUND(K*(1-H)*(1-I)-J,2)`；任一 SKU 缺价或复算不一致即停止。
- 上架流程不自动报名活动，发布后由商家批量报名。
- 视频文件上传一次，但同一视频 ID 必须逐 SKU 绑定；关系全部 `relationStatus=4` 才算完成。
- 视频素材状态 `2` 和 `4` 均可复用；复跑不得因状态 `4` 再次等待转码。
- 正式发布必须获得我的明确确认，并使用 `--publish --confirm PUBLISH_TO_JD`。
