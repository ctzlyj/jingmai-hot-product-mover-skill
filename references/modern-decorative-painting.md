# 现代装饰画适配器

## 已验证范围

- 末级类目：现代装饰画 `35381`。
- 商品类型：挂轴画、卷轴画、粘贴画、自粘墙贴画。
- 品牌：无品牌 `-1`。
- 工艺：印刷。
- 售后：支持 7 天无理由退货。
- 默认库存：每个 SKU `10000`。
- 包装尺寸与商品毛重：当前实时 Schema 非必填，不提交。
- 运费模板：店铺级配置，不写入公开类目规则。

## 销售属性维度

保持源商品真实维度数量：

- 源商品只有一个销售维度时，只发布颜色维度。即使选项名称包含 `50×100cm` 或 `8寸`，也不能额外创建尺寸维度。
- 源商品有两个维度时，才发布颜色和尺寸。
- 规格文字仍可在内部解析为尺寸，用于商家编码排序；这不等于前台需要尺寸属性。
- 发布后核对每个 SKU 的 `saleAttrs`，禁止出现源商品不存在的维度或灰色无效组合。

## 多套主图

现代装饰画固定 `mainImageMode=multi_set`，即使只有一个款式也不降级：

- 每个款式按颜色 `mappingId` 建一组。
- 第 1 张是款式专属图。
- 第 2–10 张是全商品公共图，按输入顺序提交，不因 URL 相同去重。
- 同款式不同尺寸共用同一组。
- 发布后必须从 `material.mainImages` 按线上颜色 ID 逐组审计。

## 详情图

用户提供的详情图默认全部选入并保持顺序。内容冲突、文案疑点或尺寸疑点只告警，不自行剔除；仅文件缺失、格式不支持、大小超限等接口阻断问题报错。

## 商家编码

- 挂轴画、卷轴画：`GZH + 五位款式号 + 尺寸字母`。
- 粘贴画、自粘墙贴画：`ZTH + 五位款式号 + 尺寸字母`。
- 款式号从对应前缀线上最大已用编号的下一号开始。
- 每个款式内按真实尺寸从小到大映射 `A、B、C……`。
- 单维度商品仍从颜色文本解析尺寸后缀。

例如首款四个尺寸为 `GZH10000A` 到 `GZH10000D`，第二款从 `GZH10001A` 开始。

## 逐 SKU 定价

每个真实 SKU 单独读取移动商品页 `priceFloor.ext.jdPrice`，禁止把入口 SKU 的价格复制给全部规格。

默认参数：

```text
G = 0.10
H = 0.15
I = 0.15
J = 0
K = ROUND((F-G+J)/((1-H)*(1-I)), 2)
L = ROUND(K*(1-H)*(1-I)-J, 2)
```

- `F`：源 SKU 当前价格。
- `K`：提交给京麦的京东价。
- `L`：计划活动全部生效后的预计到手价。
- 发布前验证 K、L 公式，并要求 `L=F-G`。
- 本流程不报名活动；商家发布后自行批量报名国补与直降。
