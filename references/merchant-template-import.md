# 商家三表模板导入

## 适用范围

用于读取包含 `填写说明`、`商品信息`、`SKU明细` 的装饰画商家模板，并生成现代装饰画 `35381` 的本地 `manifest.json`、`listing.json`、逐 SKU 定价校验、审核 Excel 和 `LOCAL_DRAFT` 状态。该命令不调用浏览器或京麦接口，不上传素材，不创建商品。

## 输入规则

- `商品信息` 必须提供来源平台、来源链接、来源商品 ID、标题、主图文件夹和详情图文件夹；目标固定为现代装饰画 `35381` 和多套主图。
- `SKU明细` 每个真实 SKU 一行，来源商品 ID、来源 SKU ID、商家 SKU、完整源销售属性、SKU 图片和来源当前有效价必填。
- “完整源销售属性”使用 JSON，例如 `{"颜色":"A款","尺寸":"20×30cm"}`，或使用 `属性=值|属性=值`。解析器只把跨真实 SKU 变化的属性识别为销售维度；单维度选项中的尺寸文字不得形成第二维度。
- 商家 SKU 必须以文本保存、非空、全工作簿唯一。用户值原样写入 `vendorSku`，不得按 GZH/ZTH 规则改写；GZH/ZTH 只用于未提供商家 SKU 的其他链路。
- 来源 SKU、来源有效价和素材路径逐行校验；空白公式行不算真实 SKU。

## 命令与输出

```powershell
python scripts/merchant_template_import.py `
  --input "装饰画搬运上品标准模板.xlsx" `
  --output-root "outputs/template-import"
```

每个商品生成独立目录及素材副本。`state.json` 固定为 `LOCAL_DRAFT`、`publishAllowed=false`，并声明后续仍需 AI 判重、内容合规检查和 `PUBLISH_TO_JD`。输出目录已存在时停止，禁止覆盖已有草稿。

## 停止条件

- 表头缺失、商品行或真实 SKU 行为空。
- 来源商品 ID/SKU ID 缺失或重复，商家 SKU 缺失、重复或不是文本。
- 完整源销售属性缺失、各行属性名称不一致，或真实变化维度超过两个。
- 来源当前有效价无效，库存/启用值非法，主图、详情图、SKU 图或声明的视频路径不存在。
- 目标类目不是 `35381`、主图模式不是多套主图、本地预检或逐 SKU 价格复算失败。

解析通过仅代表本地草稿结构正确，不代表已完成 AI 判重、内容合规或线上发布验收。
