# 图片上传名称超限

- 触发：本地图片名很长，例如64位哈希加扩展名。
- 失败：京东返回 `10108022204 上传图片失败，图片名称长度不能大于64`。
- 根因：原上传器把完整本地文件名直接写入 `zoneImageDTO.imgName`，没有执行远端名称长度约束。
- 修复：`scripts/jdo_listing_mvp.py` 的 `safe_upload_image_name` 保留合规短名；超限时只将远端名称替换为稳定的短哈希名，扩展名不变。本地路径、源文件字节、SKU归属和素材顺序均不变。
- 验证：`python -m unittest discover -s tests -p test_image_upload_names.py -v`。覆盖长ASCII/中文名、普通短名以及实际上传请求体，不需要联网。另已通过真实上传、商品发布和图片URL回查验证。
- 停止：缩短远端名称后仍被接口拒绝，应保存错误并停止；不要改图、重编SKU或清空已有商品ID。
